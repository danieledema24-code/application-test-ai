## Bugs, most severe first

### P4-BUG-01: The empty-Message case isn't in the Regression suite, so the demo thread's Regression run never "may submit" (MAJOR)

- **Steps:**
  1. On project J (fresh, through `phase4-journey`), as a member, open Test Execution › Run tests…
  2. Choose Regression, then Next.
- **Expected** (roadmap demo chain step 3; design §15.5, check 14): the summary lists "May submit the Contact us form (if the application does not block it)" for the empty-Message case.
- **Actual:**
  - Regression is 19 tests, and the lines are "Submits the Contact us form: 4 tests" and "Signs in with the saved test account: 7 tests" (`q1-step2.png`).
  - TC-0006 (empty Message) has `suites: []`. So do all 10 "may submit" negative cases: All automated lists "May submit …: 10".
  - The Regression run on J (RUN-0002) finished "passed" without testing a single validation rule.
  - The developers' journey picks the case through "Choose test cases…", so it never notices.
- **Where:** Phase 3 suite assignment in `backend/app/domain/testdesign/generate.py`. Negatives are never tagged `regression`. Either tag the negative form cases `regression`, or change the roadmap and design thread (product decision).

- **Steps:**
  1. Download the Playwright project from Automation on J.
  2. Unzip it, install, and run `BASE_URL=http://localhost:4100 npx playwright test`, the command in its README.
- **Expected** (P4-10 AC1): the same cases pass and fail as on the platform.
- **Actual:**

### P4-BUG-04: A retried automation job crashes, and a failed validation reads as "not checked" with no reason (MAJOR)

- **What happened** on P, while the host was heavily loaded:
  1. The `automation` job ran from 09:12:42 to 09:35:13. It then reported "Validation: 0 valid · 0 invalid · 29 not checked" (`validation.toolkit: null`, no issue) and "Gate 6: Script validation is waiting for approval".
  2. The job had been re-claimed: `jobs.attempts = 2`, and a second attempt started at 09:35:12.
  3. The second attempt failed: "Automated test scripts failed: Unexpected error: (sqlite3.IntegrityError) UNIQUE constraint failed: automation_assets.stage_run_id, automation_assets.path".
  4. The stage was left `failed`.
- **Expected:**
  - The handler is idempotent for its `stage_run_id`. A retry replaces or reuses the rows it wrote.
  - A validation that couldn't run says why (toolkit error or timeout) rather than "not checked".
  - G6 is not announced as "waiting for approval" while nothing was checked.
- **Workaround:** "Regenerate scripts" (bundle v2: 29 valid in 9 s, G6 passed automatically).
- **Where:** `backend/app/agents/automation/engineer.py:139-165` inserts `AutomationAsset` and `AutomationScript` rows for `self.run_id` without clearing earlier rows. `backend/app/agents/automation/validation.py:95-107` leaves `report = {}` when `targets` is empty or the toolkit returns nothing. A laptop sleep or an overloaded host is enough to make the reaper (`job_heartbeat_timeout_s = 60`) re-claim a live job.
